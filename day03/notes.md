Why Loops Are Needed
Loops allow the same logic to be executed repeatedly.

Backend examples:

Processing employee records
Processing transactions
Validating multiple inputs
Handling API records
for Loop Execution
Python:

Gets the next value from an iterable.
Assigns it to the loop variable.
Executes the loop body.
Repeats until no values remain.
range()
range(stop) range(start, stop) range(start, stop, step)

Examples:

range(5)

0 1 2 3 4
range(2, 6)

2 3 4 5
range(1, 10, 2)

1 3 5 7 9
